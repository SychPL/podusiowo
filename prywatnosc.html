Polityka prywatności

Aplikacja OAuth kanałów Podusiowo i Pillowville to prywatne narzędzie twórcy kanałów. Korzysta z niej wyłącznie właściciel kanałów - nie jest udostępniana innym osobom.

Jakie dane

Przez YouTube Data API i YouTube Analytics API aplikacja wysyła filmy na własne kanały twórcy oraz czyta ich statystyki (wyświetlenia, subskrypcje, czas oglądania) i listę filmów. Nie czyta danych innych użytkowników ani widzów.

Gdzie i po co

Dane są przechowywane na prywatnym serwerze twórcy i służą tylko do planowania kolejnych filmów. Nie są sprzedawane ani przekazywane osobom trzecim. Korzystanie z danych z Google API jest zgodne z Google API Services User Data Policy, w tym z wymaganiami Limited Use.

Cofnięcie dostępu

Dostęp można w każdej chwili cofnąć na stronie uprawnień konta Google. Aplikacja korzysta z YouTube API Services - obowiązują Warunki korzystania z YouTube i Polityka prywatności Google.

Privacy policy

The OAuth app of the Podusiowo and Pillowville channels is a private tool used only by the channels' owner. It uses the YouTube Data API and YouTube Analytics API to upload videos to the owner's own channels and to read their statistics and video list. It does not access data of other users or viewers. Data is kept on the owner's private server, is not sold or shared with third parties, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google Account permissions. This app uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.
